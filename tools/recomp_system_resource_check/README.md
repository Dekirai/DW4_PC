# Embedded system-resource checks

Run `scripts/test-recomp-system-resources.ps1` after preparing the patched
ModernGekko source with the normal recompilation workflow. The script finds Python
in the runtime CMake cache, or accepts its executable with `-Python`. It compiles
only the actual `Common/SystemResource.cpp`, `IniFile.cpp` and `StringUtil.cpp`
with MSVC, first with embedded resources enabled and then with the generic option
disabled. It does not build or launch the game. File-system and logging boundary functions
are supplied by the checker; the resource lookup, INI parser and conversions are
production code. Release checks use explicit failures and remain active with
`NDEBUG`.

The Python tests verify generation bounds, required DSP sizes, missing resources,
allowlisting, settings revisions and overrides, determinism, and every generated
byte and SHA-256 against the supplied redistributable service files. The C++
checks compare compiled bytes to the same files, reject traversal and unrelated
paths, cover Windows and duplicate separators, verify file and user INI
precedence, and exercise BOM, LF/CRLF, raw cheat lines, malformed inputs,
conversion failure and merge/reset behavior. Generic compilation checks that
missing resources remain unavailable while ordinary file overrides still work.

Logs, generated bytes, fresh synthetic fixtures and a JSON record containing
source hashes, compiler version and results are written to ignored
`build/recomp-system-resource-check/`. No original game assets are used. These
checks do not establish game boot, rendered font quality or audio behavior.
